## 2. The project in one page

- **Takatax**: a Philippine tax app for sole proprietors, freelancers and small businesses.
  Upload receipts, sales invoices, Forms 2307 and the COR; AI reads them; the app computes each
  BIR return line by line; verified bookkeepers, CPAs and tax lawyers can be invited in; a
  community for questions. Pitch deck at `/deck`.
- Stack: TanStack Start (React 19, TypeScript, Vite, file routes), Tailwind v4 with `tk-*`
  tokens, React Query, Vitest, Bun 1.4.4. Netlify hosts `main`.
- Supabase project `thiznrxojzrxkjwqhtjt`: Postgres with row-level security on every table,
  Auth, Realtime (chat), Edge Functions in `supabase/functions/`.
- Files: Cloudflare R2 (private bucket, signed links). AI: OpenRouter (Gemini Flash first, then
  a second and a top model when unsure; models in `supabase/functions/_shared/parser/models.ts`).
- Reader: either the Trigger.dev task `read-run` (`trigger/`) or the Supabase edge function
  `read-step`, chosen by the Supabase secret `READER` (`trigger` default, `supabase`). The live
  project uses **`READER=supabase`** because Trigger.dev deploys are blocked (section 4).
- Pricing by pages (a photo is 1 page, a PDF every page). Launch mode: `PAYMENTS_LIVE = false`
  in `supabase/functions/_shared/uploads/rules.ts`: Standard runs up to 250 pages are free;
  extra pages (₱2) and Premium (₱800 a month) show "coming soon". Payments provider: Xendit,
  built but switched off.

## 3. What was built, by session

  with page counting, documents, My COR, records assistant chat), partner dashboard and client

  "Read again" locks on click and disappears once read.

  the real reader (`src/lib/reading-progress.ts`, `src/components/app/ReadingProgress.tsx`).
- Upload: a small Proceed on each file card; logo (`src/components/site/BrandMark.tsx`,
  `public/logo.svg`, favicon, Apple touch icon); new tagline "AI for your BIR figures and tax
