# Deliverable 7: Reflection

**Takatax**, by marvin-mvm.

The whole process of creating the AI-powered web app is not the most difficult part; instead, the
idea validation, finding the right target audience and having measured data to back up the
existence of the web app itself is the most challenging part for me.

Anyone can create a web app now using LLMs and cloud services, but it could be a 'toy' app. To
justify its existence, the data from the PRD and idea validation and the target market dictate
whether it is a viable app to spend time on and even to market to the public.

I think we are in a time where the tools have already caught up to the business ideas that we
thought before were expensive and labor-consuming things to do. We normally spent a lot of money
just to get to a working prototype before generative coding existed.

With coding agents, we can ship web or SaaS products quickly, but the content and the service
type will still rely on humans and real-world validation.

As for my web app TakaTAX, I need to make sure that the output is a reliable result. I need to
adjust the model and add better screening of the file types so the LLM can identify and categorize
the files much better and reduce human correction. The goal is to make sure it is accurate in
parsing and accurate in tax amounts, so the AI must be kept up to date with BIR announcements and
tax law changes, something that is not applied to the web app yet.
